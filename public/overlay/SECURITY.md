# Security policy

Moby is used in emergencies, so we take security reports seriously.

## Reporting a vulnerability

Please **don't open a public issue.** Report it privately through
[GitHub Security Advisories](https://github.com/Xlient/Moby/security/advisories/new).

Include what you found, how to reproduce it, and the impact you expect. We aim to acknowledge reports
within 72 hours and to keep you updated until it's fixed. Please give us reasonable time to fix the
problem before you disclose it.

## Scope

- This repository (the Moby mobile app).
- The Moby service the app talks to. Please test only against your own installation or with
  permission. Never access other people's data, disrupt the service, or send false warnings.

Thank you for helping keep Moby's users safe.
